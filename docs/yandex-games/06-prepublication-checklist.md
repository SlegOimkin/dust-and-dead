# Итоговый чек-лист перед публикацией

Используйте копию этого файла для каждого билда. Отправляйте игру только после закрытия всех применимых пунктов.

## A. Аккаунт и модель публикации

- [ ] Аккаунт разработчика создан через нужный Яндекс ID.
- [ ] Предпочтительный язык связи указан.
- [ ] Командные роли и права настроены.
- [ ] Для игры создан отдельный черновик с уникальным ID.
- [ ] В **Профиле** проверено поле **Единая лицензионная схема**.
- [ ] Если единая схема подключена, документы и реквизиты заполнены в Консоли.
- [ ] Если единая схема не подключена, РСЯ создана на том же логине, оферта и реквизиты оформлены.
- [ ] Если developer-initiated рекламные вызовы не используются, это явно описано в комментарии модератору.

## B. Готовность продукта

- [ ] Игра завершена и не выглядит прототипом/демо.
- [ ] Основного содержания хватает более чем на 10 минут либо есть выраженная реиграбельность.
- [ ] Цель, правила и управление понятны.
- [ ] Сложность нарастает, сеттинг или сюжет понятен.
- [ ] Жанр и категории соответствуют геймплею.
- [ ] Возрастной рейтинг соответствует содержанию.
- [ ] Нет дубликата другой игры или подмены существующего проекта.
- [ ] Есть права на код, графику, музыку, шрифты, видео и прочие материалы.
- [ ] Нет запрещённых тем и контента.
- [ ] Нет интерактивного ИИ; заранее сгенерированные материалы проверены и встроены как статический контент.

## C. Адаптивность и управление

- [ ] Заявлены только реально поддерживаемые платформы.
- [ ] Каждая заявленная ориентация полностью работает.
- [ ] UI не растягивается и не обрезается.
- [ ] Тексты и элементы не накладываются.
- [ ] Нет системного скроллбара и swipe-to-refresh.
- [ ] Правый клик не открывает контекстное меню.
- [ ] Long tap не выделяет элементы и не открывает меню.
- [ ] Поля ввода вызывают экранную клавиатуру на мобильном.
- [ ] На мобильном всё управление доступно жестами.
- [ ] На десктопе всё управление доступно мышью/клавиатурой.
- [ ] Не используются конфликтующие системные горячие клавиши.
- [ ] Встроенное видео не открывается системным плеером и не ведёт наружу.
- [ ] Если заявлен ТВ: стрелки, OK и Back достаточны; покупок и ссылок на другие игры нет.

## D. SDK и запуск

- [ ] Архивная версия использует `<script src="/sdk.js"></script>`.
- [ ] `sdk.js` не скачан и не включён локальной копией.
- [ ] `YaGames.init()` вызывается только после загрузки SDK.
- [ ] Любой метод SDK вызывается только после завершения `YaGames.init()`.
- [ ] Ошибка загрузки/инициализации обработана понятным состоянием.
- [ ] Если используются `game_api_pause` и `game_api_resume`, подписка выполняется сразу после инициализации, а обработчики соответствуют документации.
- [ ] Независимо от выбранного механизма игра и звук останавливаются при потере фокуса и полноэкранной рекламе.
- [ ] При обработке `resume` не снимается пользовательская/меню-пауза и не включается отключённый звук.
- [ ] `ysdk.environment.i18n.lang` выбирает стартовую локаль.
- [ ] До Game Ready загружены ресурсы и данные, необходимые для первого взаимодействия; необязательная сеть не задерживает готовый UI.
- [ ] `ysdk.features.LoadingAPI.ready()` вызывается ровно после полной готовности и исчезновения загрузочных экранов.
- [ ] Если используется Gameplay API, `start()` и `stop()` соответствуют реальному геймплею.
- [ ] Debug-панель показывает актуальную инициализацию (`IT`).
- [ ] Если используется ярлык, кнопка показывается только после `shortcut.canShowPrompt()`, а награда выдаётся только при `outcome === "accepted"`.
- [ ] Если используются промоакции, query-параметры правильно сопоставлены с `environment.referrer`, а переход проверен в черновике и опубликованной версии.
- [ ] Если используются временные награды, вызывается свежее `serverTime()`, выбрана модель «24 часа» или «сутки UTC», а повторная выдача исключена.
- [ ] В TV-версии `HISTORY_BACK` открывает собственный диалог, а подтверждённый выход отправляет событие `EXIT`.
- [ ] Если показываются другие игры разработчика, ссылки получаются через `GamesAPI`; ошибки и недоступность обработаны, а на TV блок скрыт.
- [ ] Если есть внутриигровой fullscreen-контрол, он учитывает текущий `screen.fullscreen.status` и ограничения браузера.
- [ ] Если используется `clipboard`, игра рассчитывает только на документированную запись строки и обрабатывает недоступность функции на уровне интерфейса.

## E. Сохранения и авторизация

- [ ] Гостевой режим полностью работоспособен.
- [ ] Гостевой прогресс сохраняется.
- [ ] Авторизация предлагается только после отдельного нажатия.
- [ ] До окна входа объяснена польза.
- [ ] Отказ от входа не блокирует игру.
- [ ] Прогресс сохраняется после значимых действий или по понятной кнопке.
- [ ] Обновление страницы не уничтожает прогресс.
- [ ] Ошибки сохранения и лимиты запросов обработаны.
- [ ] Для облачных сохранений включён соответствующий флаг черновика.
- [ ] При смене гостевого/авторизованного прогресса данные запрашиваются заново.
- [ ] Старый `player.getID()` не используется в новом коде; применяется `getUniqueID()`.
- [ ] На собственном домене для iOS используется `safeStorage` или облачное хранение.

## F. Реклама

- [ ] Вся реклама вызывается только SDK Яндекс Игр.
- [ ] Нет сторонних блоков, рекламных картинок или текста.
- [ ] Нет имитации платформенной рекламы.
- [ ] Нет кастомных RTB-блоков; единственный дополнительный формат — стики-баннер.
- [ ] Ориентация рекламного блока соответствует ориентации игры.
- [ ] Автоматическая стартовая реклама не запускает звук/геймплей во время показа; при использовании событий это проверено через pause/resume.
- [ ] Interstitial показывается только в разрешённой логической паузе.
- [ ] Показ, привязанный к допустимому неигровому или условно-пошаговому действию, начинается не позднее 0,33 секунды.
- [ ] В real-time уровне короче 5 минут interstitial внутри уровня отсутствует.
- [ ] В real-time уровне длиннее 5 минут таймерный показ имеет заметное предупреждение 2 секунды.
- [ ] Во время предупреждения, interstitial и rewarded геймплей и звук стоят на паузе.
- [ ] `onClose(false)` и `onError` не блокируют продолжение.
- [ ] Завершающая логика рекламы выполняется ровно один раз.
- [ ] Rewarded запускается только по добровольной понятной кнопке.
- [ ] Кнопка заранее называет конкретную награду.
- [ ] Без rewarded основной геймплей остаётся доступен.
- [ ] Награда выдаётся только в `onRewarded`, ровно один раз, и сохраняется.
- [ ] Стики-баннер не перекрывает UI.
- [ ] Для товара no-ads отключены interstitial, rewarded и стики; для стики заранее включено управление через API.
- [ ] Подавление автоматической стартовой рекламы для no-ads подтверждено платформой/поддержкой либо товар не обещает полное отсутствие всей рекламы.
- [ ] Возврат по рекламной ссылке не сбрасывает состояние игры.

## G. Покупки, если применимо

- [ ] Все платежи выполняются только через SDK Яндекс Игр; внешние платежи и микротранзакции отсутствуют.
- [ ] Покупки отсутствуют на TV-версии.
- [ ] Все товары созданы и активны в Консоли.
- [ ] Ассортимент игры совпадает с Консолью.
- [ ] Название, описание, изображение и фактический товар совпадают.
- [ ] Цена показана цифрами.
- [ ] Название и иконка портальной валюты получены через SDK.
- [ ] Покупки и связанный прогресс доступны одному пользователю с разных устройств.
- [ ] Расходуемый товар сначала начисляется и сохраняется, затем консумируется.
- [ ] Постоянная покупка не консумируется.
- [ ] Выполняется проверка `getPurchases()`: результаты обрабатываются идемпотентно, расходуемые товары начисляются и затем консумируются, постоянные не консумируются.
- [ ] Один `purchaseToken` нельзя начислить повторно.
- [ ] Для ценных покупок подпись проверяется на доверенном сервере.
- [ ] Тестовый логин добавлен.
- [ ] Проверены успех, отмена, ошибка, потеря сети и повторный запуск.

## H. Архив и внешние ресурсы

- [ ] ZIP распаковывается без ошибок.
- [ ] В корне находится один `index.html`.
- [ ] Размер после распаковки не больше 100 МБ.
- [ ] В именах нет пробелов и кириллицы.
- [ ] Относительные пути работают с адреса платформы.
- [ ] Нет абсолютных URL к S3 Яндекса, кроме официального SDK-адреса в согласованном сценарии собственного домена.
- [ ] Нет проверки домена, блокирующей игру.
- [ ] Каждый внешний хост заявлен в Настройках.
- [ ] У хостов нет HTTP/WS, IP, порта или пути в заявке.
- [ ] Ошибка внешнего API показывает понятное сообщение и действие восстановления.
- [ ] CSP проверена.
- [ ] `iframe` согласован с поддержкой, если используется.

## I. Черновик и локализация

- [ ] Версия соответствует текущему билду.
- [ ] Платформы и ориентация указаны точно.
- [ ] Для iOS заполнен Apple Team ID.
- [ ] Выбраны только реально переведённые языки.
- [ ] Каждая локаль проверена через debug-панель.
- [ ] До двух категорий выбраны корректно.
- [ ] До 20 тегов соответствуют содержанию.
- [ ] Ключевые слова в нижнем регистре, через запятую, до 100 символов.
- [ ] Название уникально, до 50 символов, совпадает в игре и материалах.
- [ ] SEO-описание: 50–160 символов.
- [ ] «Об игре»: 100–1000 символов.
- [ ] Короткое описание: до 70 символов.
- [ ] «Как играть»: 100–1000 символов.
- [ ] Тексты грамотны, не повторяются и не заполнены искусственными символами.
- [ ] Комментарий модератору описывает нестандартные сценарии.
- [ ] Отсроченная публикация включена заранее, если релиз должен быть ручным.

## J. Материалы

- [ ] Иконка: PNG, 512 × 512.
- [ ] Обложка: PNG, 800 × 470.
- [ ] Обложка на витрину, если есть: PNG/JPG, 1560 × 520.
- [ ] Иконка и обложка не являются скриншотами.
- [ ] Нет рамок, скруглений, системного UI или интерфейса Яндекс Игр.
- [ ] Нет артефактов, обрезанного текста и неправильных чёрных полос.
- [ ] Название на материалах совпадает с локалью.
- [ ] Скриншоты: 16:9 или 9:16, длинная сторона 1280–2560.
- [ ] Формат скриншотов: JPEG или 24-битный PNG.
- [ ] Есть минимум два скриншота для каждой заявленной группы платформ.
- [ ] Реальный геймплей занимает не менее 70% скриншота.
- [ ] Gameplay-видео: MP4, до 28 секунд, до 100 МБ, высота от 400 px.
- [ ] Реальный геймплей занимает не менее 70% обычного видео.
- [ ] Значимые надписи переведены на язык материала.
